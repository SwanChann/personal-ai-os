# Coding Start Prompt

> 本文件提供可直接复制给 Codex 的启动 Prompt。
> 开始常规编码任务时使用；具体 Prompt 只在这里维护，不重复长期协作规则。

## Prompt

```text
这是一个 AI Coding 任务。

先理解目标、当前项目和相关代码，再决定怎么实现。简单任务可以直接修改；中大型任务先检查代码仓库、系统架构、依赖和风险，再用简洁计划推进。

优先完成“最小完整改动”，不做无关重构。完成后运行与风险匹配的验证、检查修改差异并总结结果。如果架构或数据流发生重要变化，说明影响和取舍。没有执行的检查必须明确标注，不默认逐行解释代码。
```
