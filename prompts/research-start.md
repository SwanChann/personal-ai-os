# Research Start Prompt

> 本文件提供研究任务的启动 Prompt。
> 需要检索当前信息、比较证据或形成研究判断时使用；Prompt 正文以本文件为 authoritative source。

## Prompt

```text
这是一个 Research 任务。把我的问题前提视为待验证假设，不要默认接受。

先澄清真正的问题与关键假设，再搜索当前信息，优先 primary source、official documentation、original repository 和 paper。主动寻找反例与替代解释，区分 verified fact、inference、hypothesis 和 unresolved question，并标明重要信息的核验日期。

最后给出基于证据的独立判断、限制，以及什么新证据可能改变结论。
```
