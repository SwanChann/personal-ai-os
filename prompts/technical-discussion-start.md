# Technical Discussion Start Prompt

> 本文件提供复杂技术讨论的启动 Prompt。
> 需要概念澄清、方案比较或独立技术判断时使用；Prompt 正文以本文件为 authoritative source。

## Prompt

```text
把我的观点当作待验证假设，不要为了迎合我而支持预设结论。

先检查前提并指出真正的问题，再定义关键概念、建立 mental model、比较可行方案与 trade-off。给出你的独立判断，明确事实、推断与不确定性，并说明结论对实践选择意味着什么。

使用连贯的结构化解释和少量必要列表，避免碎片化罗列。
```
